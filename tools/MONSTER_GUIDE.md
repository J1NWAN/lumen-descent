# 루멘 디센트 몬스터 리그 작성 가이드

새 스타일의 목표: **어둡고 묵직한 다크 판타지 2D**. 손으로 그린 듯한 벡터지만 입체감이 확실해야 합니다.
- 조각마다 원통·구 음영이 있습니다.
- 가장자리에 그늘이 지고, 왼쪽에서 따뜻한 림라이트, 오른쪽에서 차가운 림라이트가 들어옵니다.
- 금속에는 하이라이트, 표면에는 질감 노이즈가 있습니다.
- 눈과 균열처럼 빛나는 부분만 강한 색을 씁니다.

귀엽거나 만화 같은 얼굴은 금지입니다.
- 웃는 입, 동그랗고 큰 눈알, 아동 체형을 쓰지 않습니다.
- 위협적이고 굶주린, 오래된 느낌을 냅니다.

## 반드시 먼저 읽을 견본
- `src/mon/f1_moss.js` 의 `mossClump`: 점액/덩어리형(blob)
- `src/mon/f9_ember.js` 의 `ashHound`: 네발 짐승형(beast)
- `src/mon/f5_ossuary.js` 의 `skeletonGuard`: 인간형(biped)
- `src/rig.js`: 키트 함수(part, limb, plate, eye, glow, spikes, crack, rivet, along)와 유형별 동작 생성기(makeActions, makeIdle)
- `src/heroes.js`: 영웅 3명. 같은 화풍의 기준입니다.

## 틀
- 뷰박스는 **200×200**, 바닥선은 **y=188**입니다.
- **왼쪽(영웅 쪽)을 바라봅니다.** 앞쪽은 -x입니다.
- 평소 자세는 대략 x 14~186, y 12~188 안에 들어가게 합니다.
  - 보스(`art.sc` 1.5 이상)도 같은 200×200에 그립니다. 게임이 CSS로 키우므로, 틀을 꽉 채우는 웅장한 실루엣으로 그립니다.
- 크기 배율은 게임이 `engine.js` 의 `art.sc` 로 적용합니다. 그림 안에서 따로 줄이거나 키우지 않습니다.
- 등록 방법: `R.monster('id', { arch, mods, bones, layers(k){...}, order, sockets, springs, shadow })`
  - 파일은 각 층 파일 하나입니다(`src/mon/fN_xxx.js`).
  - 맨 위의 `(function(){ const R = window.RIG; ... })();` 틀을 유지합니다.

## 뼈대 이름 (동작 생성기가 이 이름으로 움직입니다)
| 이름 | 쓰임 |
|---|---|
| `root` | 반드시 있어야 합니다. 피벗은 바닥 중심(예: [100,188]). 부모는 null |
| `body` | 몸통. 보통 root의 자식이고, 피벗은 몸의 무게중심이나 골반 |
| `head`, `jaw`, `neck` | 머리(body 자식), 아래턱(head 자식, 피벗은 턱관절), 목(뱀형) |
| `armF`, `armB` | 가까운 쪽 / 먼 쪽 팔·앞다리·집게 (피벗은 어깨) |
| `legF`, `legB` | 가까운 쪽 / 먼 쪽 다리·뒷다리 (피벗은 엉덩이) |
| `tail` | 꼬리 |
| `wingF`, `wingB` | 날개 (피벗은 날개 뿌리) |
| `ex1` ~ `ex4` | 촉수·더듬이·떠다니는 조각·버섯갓 같은 기타 부속. 대기 때 자동으로 흔들립니다 |

- 각 항목 형식: `[이름, 부모, 피벗x, 피벗y]`. 부모가 먼저 나와야 합니다.
- 다리를 `root` 의 자식으로 두면, 몸통이 기울어도 발이 땅에 붙어 있습니다(skeletonGuard 참고).
- 짐승형은 다리를 `body` 의 자식으로 둡니다. 그래야 덮칠 때 몸과 함께 날아갑니다.

## 유형 `arch` 고르기
- `biped`: 사람형. 기본값
- `beast`: 네발 짐승 (덮치기)
- `blob`: 점액·덩어리 (찌그러졌다 늘어나기)
- `flyer`: 날개로 나는 것 (호버링, 날갯짓, 급강하)
- `floater`: 떠다니는 유령·정령·눈알·조각 (부유)
- `serpent`: 뱀·장어·벌레 (목을 뒤로 뺐다가 물기)
- `construct`: 골렘·기계·문·종 (무겁게 내려찍기)

`mods` 로 동작 크기를 조절합니다.
- `lunge`: 앞으로 나가는 거리. 기본 40
- `jaw`: 턱을 벌리는 각도
- `arm`: 팔 휘두름 배수
- `heavy`: 동작 시간 배수 (construct 보스는 1.2)
- `lift`: 시전할 때 떠오르는 높이

특정 동작을 바꾸고 싶으면 `actions: { attack: {dur, hitAt, keys:[...]}}` 로 덮어씁니다.
- 자세 값 형식: `{ 뼈: [회전°, x, y, sx, sy] }`
- 왼쪽을 볼 때 회전 약속:
  - 몸통을 앞으로 숙이기 = **음수**
  - 아래로 늘어진 팔의 손을 앞으로 내밀기 = **양수**
  - 턱 벌리기 = **음수**

## 레이어(그림)
- `layers(k)` 는 `{레이어이름: SVG문자열}` 을 돌려줍니다.
- `order: [[레이어, 뼈], ...]` 순서대로 쌓입니다. 앞에 있을수록 뒤에 그려집니다.
  - 먼 쪽 다리·팔을 먼저, 몸통, 가까운 쪽, 머리·턱 순서로 둡니다.
- 같은 뼈에 여러 레이어를 붙여도 됩니다. 예: 방패는 먼 팔(armB)에 붙이되 몸 앞에 그리기.
- 모든 좌표는 **휴식 자세의 월드 좌표**로 그립니다. 뼈가 움직이면 해당 레이어가 피벗을 기준으로 돌아갑니다.
- 한 뼈의 레이어에는 그 뼈에 붙은 부분만 넣습니다. 머리는 head, 아래턱은 jaw, 팔은 armF.

## 키트 (k)
- `k.part(d, fill, opt)`: 기본 조각. 바탕색, 음영, 질감, 가장자리 그늘, 림라이트, 외곽선을 한 번에 칠합니다.
  - `ball:1`: 구형 음영 (살덩이·버섯·알)
  - `cyl`: 원통 음영의 세기 (0~1)
  - `tex`: 노이즈 질감 (0~1)
  - `aoW`: 가장자리 그늘 폭
  - `spec:['M..']`: 금속·젖은 표면의 하이라이트 선
  - `inner`: 조각 안쪽에 잘려 들어갈 세부(주름·균열·무늬)
  - `pat:'scale'|'mail'`: 비늘·사슬 무늬
  - `rimW`: 림라이트 굵기
  - `lw`: 외곽선 굵기
  - `rim:0`, `line:0`: 림라이트·외곽선 끄기
- `k.limb(x1,y1,x2,y2,w1,w2,fill,opt)`: 원통형 팔다리 한 마디
  - 짐승 다리처럼 이어져야 하는 곳은 limb을 여러 개 잇지 마세요. 관절이 끊겨 로봇처럼 보입니다. `part` 로 한 덩어리 경로를 그립니다(ashHound 참고).
- `k.plate(...)`: 볼록한 판금 (갑옷·갑각)
- `k.eye(x,y,r,color,{pupil:'slit'|'dot', sq:0.5, glow, noBlink})`: 빛나는 눈. 깜빡임이 자동으로 들어갑니다.
  - 위협적인 눈은 `sq:0.5~0.65` 로 가늘게 뜨고, 눈썹·눈두덩 그늘을 함께 그립니다.
- `k.glow(x,y,r,color,op)`: 흐린 발광
- `k.spikes([[x,y,각도,길이],...], L, color, 폭)`: 가시·뿔·갈기
- `k.crack(d, color)`: 빛이 새는 균열선
- `k.rivet(x,y,r)`: 황동 리벳
- `k.K`: 이 리그의 정의 접두어
  - `url(#${K}b1)`, `${K}b3`, `${K}b8`: 블러
  - `${K}blade`: 칼날 그라디언트
  - `${K}ember`: 잿불 그라디언트

## 색과 조명
- 바탕은 **어둡고 채도 낮은 색**으로 칠합니다. 예: 이끼 #2c4624, 숯 #2c2422, 녹슨 철 #3e3a38, 뼈 #cfc4ac.
- 강조색은 `engine.js` 의 그 적 `art.e` 색을 씁니다. 눈·균열·핵에만 쓰고 넓게 칠하지 않습니다.
- 외곽선은 #07050a 입니다. 순수한 #000 바탕은 쓰지 않습니다.
- 그 층의 배경과 어울려야 합니다.

## 세부 수준
- 한 몬스터에 조각 15~45개 정도를 씁니다.
- 게임에서 실제로 보이는 크기는 90~220px입니다. **실루엣과 눈이 작은 크기에서도 읽혀야** 합니다.
- 들어가면 좋은 표현: 주름, 갈라짐, 갈비뼈, 비늘, 녹, 리벳, 해진 천, 늘어진 뿌리, 물방울.

## 2차 동작
- 꼬리·더듬이·촉수·천은 `springs: [R.trailSpring('tail', 0.1, 50, 6, 5, 1.6)]` 로 처리합니다.
  - 인자: 뼈, 따라오는 정도, 강성, 감쇠, 흔들림 크기, 흔들림 속도
  - 몸이 움직일 때 뒤로 처졌다가 따라옵니다.
- 특수 효과(빛 깜빡임, 회전하는 톱니 등)는 `setup(svg,kit)` / `tick(e,t,st,dt,bones)` 로 구현합니다. heroes.js 의 noa 참고.
  - 회전하는 부품은 `ex1` 뼈의 대기 동작을 `idleMods: { extra(t,w,o){ o.ex1=[t*90,0,0]; } }` 로 덮어쓰는 방법도 있습니다.

## 소켓
`sockets: { core: [x,y,'body'], mouth: [x,y,'jaw'] }`
- `core`: 맞았을 때 이펙트가 터지는 중심. 필수입니다.
- 공격 기원점(입·무기·집게 끝)은 이름 자유입니다.

## 검증 (반드시 직접 보고 고치기)
```
python3 tools/riglab.py check                         # 생성 오류와 미작업 목록
python3 tools/riglab.py sheet /tmp/x.png id1 id2 ...  # 정지 자세 모음
python3 tools/riglab.py big /tmp/x.png id             # 크게(정지 + 공격 순간)
python3 tools/riglab.py frames /tmp/x.png id          # 공격/방어/피격/시전/사망 프레임
```
- 이미지는 Read 도구로 직접 봅니다.
- 각 몬스터마다 다음을 확인합니다.
  1. 정지 자세가 귀엽지 않고 위협적인가
  2. 형태가 무엇인지 즉시 읽히는가
  3. 동작할 때 조각이 떨어져 나가거나 이상하게 꺾이지 않는가
  4. 사망 때 자연스럽게 무너지는가
  5. 틀 밖으로 크게 삐져나가지 않는가
- 만족할 때까지 고칩니다.
- 이름과 콘셉트는 `src/engine.js` 의 `ENEMIES` 항목을 따릅니다. 이름, 행동(moves), 설명(desc)을 봅니다.
- 기존 그림은 `src/art.js`, `src/art2.js` 의 `M.<id>` 에 있습니다. 콘셉트(무엇인지, 특징 부위)는 유지하되 그림은 새로 그립니다.

## 하지 말 것
- 다른 층 파일, rig.js, heroes.js, engine.js, ui.js 는 수정하지 않습니다.
  - 엔진에 꼭 필요한 기능이 있으면 보고만 합니다.
- 외부 이미지나 라이브러리를 쓰지 않습니다. 모두 코드로 그립니다.
- 무작위로 모양을 바꾸지 않습니다. 같은 몬스터는 늘 같은 모양이어야 합니다. 난수는 시드 고정으로만 씁니다.
